# Zepto SQL Analysis

## Project Overview
This project analyzes Zepto product dataset using PostgreSQL and SQL queries to generate business insights.

## Tools Used
- PostgreSQL
- pgAdmin 4
- SQL

## Dataset
Zepto product dataset containing categories, prices, discounts, ratings, and stock details.

## Key Analysis Performed
- Top discounted products
- Category-wise product analysis
- Price distribution
- Out-of-stock products
- Rating analysis
- Inventory insights

## Files Included
- zepto_v2.csv → Dataset
- zepto_analysis.sql → SQL queries
- Screenshots of query outputs
